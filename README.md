# How to install

1.Tạo mới một folder, mở terminal trong folder đó, clone repo này bằng lệnh
```
git clone https://github.com/huycq225724/TemplateHub
```
hoặc download file zip và extract

2. Bên trong folder đó, mở terminal và chạy các lệnh
```
npm install
```
và 
```
npm run dev
```
nếu bị lỗi thường là do chưa cài dặt vite, cài xong và chạy lại.

3. Sau khi chạy "npm run dev", terminal sẽ hiển thị 1 đường link (thường là http://localhost:5173/). Mở đường link đó trong trình duyệt.
